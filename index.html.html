Export kaise karein

  1. Plain HTML: seedha index.html download hoti hai, images andar hi hoti hain. Kahin bhi chalti hai, par ye AMP/Google Web Story nahi hai.
  2. AMP: pehle Story SEO tab bharo (canvas ke khali hisse par click karo). Publisher logo (square) aur poster image (3:4) ka https URL zaroori hai, warna AMP story blank dikhti hai. Story SEO tab me ab Image Manager hai: logo (96×96) aur poster (640×853) ka URL daalo ya seedha upload karo — uploaded image ZIP export ke assets/ folder me apne aap chali jaati hai.
  3. AMP ZIP extract karo aur GitHub repo ke stories/my-story/ me upload karo. AMP story double-click se nahi, https link se kholo: https://USERNAME.github.io/REPO/stories/my-story/story.html
  4. Wohi URL Canonical me daalo aur dobara export karo. Blogger post me HTML view me link daalo:
<a href="https://USERNAME.github.io/REPO/stories/my-story/story.html">Story dekho</a>

AMP check karne ke liye published URL validator.amp.dev me daalo. Google Search/Discover me aane ki guarantee nahi hoti.

☁ GitHub par seedha publish

Story ka AMP HTML + images aapke GitHub repo me chali jaati hain aur GitHub Pages se live ho jaati hain.
Domain daaloge to story ka link usi domain par banega aur repo me CNAME file judegi. Domain ke DNS me ek CNAME record bhi banana hoga (publish ke baad steps dikhenge). Blogger wala main blog domain nahi chalega, uska subdomain use karo. Har publish par is story ka link sitemap.xml me jud jaata hai. Search Console me sitemap sirf ek baar submit karna hota hai. Paste na chale to field par 2 second dabake rakho, ya upar ka 📋 Paste button dabao.
Token kaise banayein?
  1. github.com → profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access → Only select repositories → apna stories repo chuno
  3. Permissions → Repository permissions → Contents: Read and write (Pages: Read and write bhi de sakte ho)
  4. Generate karke token copy karo aur upar paste karo
Token password jaisa hai: shared computer par mat save karo, editor file kisi ko dene se pehle token hatao. Ye project JSON ya export me kabhi nahi jaata.
